## Ponytail workflow

Use the smallest change that solves the full task. Start with the existing components, then platform APIs and installed dependencies. Add abstractions only when they simplify the code that needs to change.

Check the affected callers and verify the outcome through the normal app flow. Follow the [official Ponytail guide](https://github.com/DietrichGebert/ponytail/tree/main/skills/ponytail) when the skill is available.
